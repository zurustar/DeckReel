# 開発と検証

## 構成

GoのCLIと `internal/deckreel` がPPTX解析・原稿処理・VOICEVOX接続・工程管理を担当します。
`internal/native` は埋め込んだmacOS用ヘルパーを検証・展開して呼び出します。
`native/main.swift` がCoreGraphicsによるPDF描画とAVFoundationによるH.264/AAC生成・パススルー結合を担当します。
ヘルパーのコンパイルは開発時のみ。利用者のMacでSwiftを実行・コンパイルすることはありません。

## テスト

```sh
go test -race ./...
go vet ./...
```

Macでは先に `./scripts/build.sh` でヘルパーを生成してください。
macOS専用テストはPDFを生成し、PNG化、短い動画の生成、24クリップのパススルー結合と尺検査を行います。
PowerPointやVOICEVOXのインストールをCIに要求しません。その代わり以下の実機項目はCIの成功だけで完了と判断しません。

### 実機で確認すること

1. PowerPointをインストールしたMacで、日本語ノート・図版・非表示・4:3を含む資料を変換する。
2. オートメーションの初回許可、PowerPointのダイアログがある場合、拒否・タイムアウト時の動作を確認する。
3. PowerPointの既存資料が変更・保存・閉鎖されないことと、入力PPTXのハッシュが変わらないことを確認する。
4. PDF出力が元のスライド順を保つことと、非表示スライドの扱いを確認する。実装はPDFが全ページなら元の位置、表示ページのみなら表示順で対応させ、どちらにも一致しない枚数は拒否する。
5. 実際のVOICEVOX Engineで `--list-speakers`、指定スタイル、速度変更、専門用語と長文を確認する。
6. 音声の末尾、各スライド境界、長尺資料での音ずれを聴取・確認する。フレーム尺検査は聴取確認の代用にならない。
7. 原稿1枚だけの修正、tailだけの修正、途中のCtrl-C、再実行、ディスク容量不足を確認する。
8. 開発ツールのないMacで配布物を検証する。Developer ID署名、公証、Gatekeeper、展開後のヘルパーの起動を確認する。

### 制限

- PowerPointのAppleScript命令は実機確認が残っています。失敗時に手動PDF出力へ黙って切り替えません。
- スライドのアニメーション・埋め込み動画は静止画として出力します。
- 1スライドの原稿は最大10,000文字、PPTXは512MiBまで。音声応答は128MiBまでです。制限超過は停止して資料の分割を案内します。
- VOICEVOXは `/version`、`/speakers`、`/core_versions`、`/engine_manifest`、`/user_dict`、`/audio_query`、`/synthesis` を提供するEngineを対象とします。対応する正式なバージョン範囲は実機検証後に固定します。
- 音声はWAV・PCM16・48kHz・モノラルを要求し、異なる形式を勝手に解釈しません。
- Engineは利用者が起動します。接続先はループバックのみで、外部ホストやリダイレクトは許可しません。
- Engine・モデル・Engine辞書の識別情報をキャッシュ条件に含めます。同じ識別情報のままモデルを置換した場合は `--model-revision` に新しい値を指定してください。
- 描画環境のフォント一覧・フォントファイルの更新日時・サイズを追跡します。検出できない変更には `--render-revision` を指定してください。
- 速度は初期版では0.5〜2.0に制限します。話者ごとの適正値は試聴して選んでください。

## 状態と保存

`manifest.json` は工程のキー・成功状態・成果物のSHA-256を保持します。
画像はPowerPointの書き出し結果を正規化したPNGにし、原稿のみの変更時も同じ画像なら既存クリップを再利用できます。
実行途中の成果物は一時フォルダで生成し、検査後に移動します。`running`・`failed`・`interrupted` は再利用しません。
同じ作業フォルダとPowerPoint操作はファイルロックで排他制御します。

既存MP4は最後まで維持します。新しい完成動画を検査し、出力先と同じファイルシステムへコピーした後に公開します。
上書き指定なしではハードリンク作成による存在検査を使うため、実行途中に別プロセスが出力を作成しても置換しません。

## 正式リリースまで

ネイティブヘルパーの採用によりFFmpegを再配布しません。
`DECKREEL_SIGN_IDENTITY` を指定するとビルドスクリプトは指定IDで署名しますが、公証まで自動化するものではありません。
PowerPoint自動操作・VOICEVOX・長尺品質・署名と公証の実機確認を終えるまでは開発版として扱います。
